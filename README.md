# ПарДозор — руководство пользователя

Полная инструкция по работе с прибором: <https://kvadkl.github.io/pardozor-manual/>.

Это самостоятельный справочный сайт, не демонстрационный стенд. Он не подключается к устройству и не посылает ему команды. Существующий сайт с записями испытаний остаётся отдельно: <https://kvadkl.github.io/pardozor-demo/>.

Содержание проверено по интерфейсу и логике прошивки **0.5.0-dev.104**. Здесь нет исходного кода прошивки, паролей сетей, резервных копий памяти или журналов реальных сеансов.

## Содержание

33 главы: первый запуск, локальный экран и энкодер, подготовка, температурные каналы и калибровка по ROM, процессы и шаблоны, этапы, работа на себя, клапан, ШИМ и снижение, практические сценарии, весы и цель, калькулятор, оповещения, Wi-Fi, журналы, отчёт, настройки, диагностика, обновление и поиск неисправностей.

Оглавление, поиск по всему тексту, прямые ссылки на главы и подразделы, мобильная навигация, печать главы или всего руководства в PDF через браузер. Без JavaScript доступен полный текст всех глав.

## Редактирование и проверка

Требуется Python 3.10+ для сборки; опубликованный сайт не требует сервера приложений, библиотек или Python.

```powershell
python build.py
python -m unittest discover -s tests -v
python -m http.server 8091 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:8091/>. Для браузерной проверки нужен установленный Python Playwright и Chrome:

```powershell
python tests/browser_check.py
```

Этот тест сам запускает временный локальный HTTP-сервер и закрывает его по окончании. Результаты и снимки экрана пишутся в `test-results/`, не публикуются.

- `src/chapters.py` — проверенный текст глав.
- `build.py` — генерация статического `index.html`.
- `assets/style.css`, `assets/app.js` — оформление и навигация; без внешних зависимостей, аналитики и запросов к прибору.
- `assets/*.jpg` — реальные фотографии устройства.
- `index.html` — готовая страница; после изменения глав пересоберите и включите результат в коммит.

## GitHub Pages

Публикация из ветки `main`, папка `/`. Файл `.nojekyll` отключает обработку Jekyll. Все локальные ресурсы используют относительные пути и работают по адресу `/pardozor-manual/`. Не требуется добавлять секреты, ключи API или данные прибора.

Перед публикацией изменений проверяйте соответствие конкретной версии прошивки. Не описывайте планы развития как уже доступные функции; параметры шаблонов — не универсальные технологические рекомендации.
